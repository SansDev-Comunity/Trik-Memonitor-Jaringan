# Trik-Memonitor-Jaringan

Memonitor jaringan bukan pekerjaan yang hanya bisa di lakukan oleh administrator. Anda sebagai pengguna internet perorangan pun bisa melakukan nya di rumah. Tugas-tugas monitoring jaringan seperti menguji konektivitas, memeriksa rute, informasi domain, dan memeriksa port-port yang terbuka tidaklah serumit yang Anda bayangkan.
